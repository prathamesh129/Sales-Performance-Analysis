# Sales Performance Analysis

## Project Overview
A data analysis project using SQL and Power BI to analyze sales performance, customer behavior, product performance, and regional sales trends. The dashboard provides insights to support business decision-making.

## Tech Stack
- MySQL
- MySQL Workbench
- Power BI Desktop
- Power Query
- DAX
- Microsoft Excel (Dataset)

## Data Source

Dataset: Public Sales Dataset downloaded from Kaggle.
The dataset contains sales transaction records, including order details, customer information, product categories, regions, and sales values. It was used to perform sales analysis and build an interactive Power BI dashboard.

## Project Features
- Sales KPIs
- Customer Analysis
- Product Performance
- Category-wise Sales
- Region-wise Sales
- SQL Analysis
- Interactive Dashboard

## Key Insights
- Total sales and order performance.
- Top-performing customers and products.
- Category and regional sales trends.
- Interactive dashboard for business analysis.
